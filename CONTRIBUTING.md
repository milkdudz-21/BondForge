# Contributing to BondForge

Thanks for helping improve BondForge, a RuneScape 3 crafting profit and Bond progress tracker.

## Where to post

- **Bugs:** Use the [Bug report](https://github.com/milkdudz-21/BondForge/issues/new/choose) template. Include your version, steps to reproduce, expected/actual results, and any relevant error text.
- **Feature requests:** Use the [Feature request](https://github.com/milkdudz-21/BondForge/issues/new/choose) template.
- **Questions, tips and open-ended ideas:** Use [Discussions](https://github.com/milkdudz-21/BondForge/discussions).

Please search existing Issues and Discussions before posting. Keep reports constructive and remove account names, credentials and other personal details from screenshots or logs.

## Reporting calculation problems

Include the tracked item ID, entered selling price, material cost, Bond price, and the result you expected. BondForge uses estimated prices and inventory increases; it does not verify completed sales.

## Code contributions

Before submitting code changes, open an Issue to discuss the approach. Keep changes focused, explain testing performed, and avoid breaking saved settings or the internal plugin identifier `MembershipGoalAutoPrice`.

No open-source licence has been selected for this repository. Please ask the maintainer before redistributing or modifying the code outside GitHub's default permissions.
